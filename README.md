# COVER Form Guide Prototype

An interactive prototype for the COVER page form with integrated field guidance.

## Features

- **Interactive Form Fields** - All 10 fields from the COVER page
- **Split-Panel Layout** - Form on left, detailed field guidance on right
- **Click-to-Learn** - Click any field to see tips, requirements, and format specifications
- **Visual Distinction** - Read-only fields clearly marked vs. editable fields
- **Responsive Design** - Works on desktop and mobile devices

## Fields Included

1. Project Name (Editable)
2. Text_Matrix (Editable)
3. Registry ID (Read-only)
4. Project Start Date (Editable)
5. Issuing Period Start & End Date (Editable)
6. Submission Purpose (Radio buttons - Editable)
7. Document Version (Editable)
8. First Issue Date (Editable)
9. Last Issue Date (Editable)
10. SBS Standard Version (Dropdown - Editable)

## How to Use

1. Open `index.html` in your web browser
2. Click on any form field to see guidance in the right panel
3. Explore tips, descriptions, and formatting requirements for each field

## Local Setup

```bash
# Clone the repository
git clone https://github.com/mojisua/cover-form-guide.git

# Open in browser
open index.html
```
